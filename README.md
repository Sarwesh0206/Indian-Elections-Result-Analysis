# 🗳️ Indian General Election Results Analysis 2024 | Power BI Dashboard

An interactive **Power BI dashboard** that analyzes the **2024 Indian General Election Results** using data visualization, DAX, and Power Query. The project transforms raw election datasets into meaningful insights through dynamic dashboards, maps, KPIs, and drill-through analysis.

---

## 📌 Project Overview

This project provides a comprehensive analysis of the **2024 Lok Sabha Election Results** by visualizing:

- Alliance-wise seat distribution
- Party-wise performance
- State-wise election results
- Constituency-level analysis
- Candidate rankings
- Vote share and winning margins

The dashboard enables users to explore election outcomes through an intuitive and interactive interface.
